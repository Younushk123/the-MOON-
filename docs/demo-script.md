# Demo Script

1. Open the Overview and explain mock versus PSI data labels.
2. Browse PSI-159 Experiment Explorer and open an experiment.
3. Compare normal and inverse records.
4. Ask the AI assistant a limited question and point out evidence or abstention.
5. Open **Microgravity Flame Explorer**.
6. Upload a still image or the supported FLEX MP4.
7. Explain that results are PSI-69 pixel features and are not physical calibration.
8. Keep results separate from PSI-159 experiment records.
