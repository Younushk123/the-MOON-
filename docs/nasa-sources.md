# NASA Sources

The project distinguishes catalogue metadata, downloaded documents, indexed documents, raw data, and verified
claims. Source status must not be inferred from a URL or filename alone.

- PSI-159 is represented by locally processed normal and inverse flame CSV data.
- PSI-69 FLEX video and still-image analysis are recording-specific and not general-purpose detectors.
- Source IDs, URLs, downloaded files, and ingestion state belong in the RAG source register.
- Any Moon or Mars relevance is interpretive, not direct experimental evidence.
