# THE MOON - Core Foundation

Initial core development foundation for THE MOON NASA Space Apps project.

## Current Modules

- Experiment Schema v0.1
- Synthetic Mock Experiment Dataset
- Basic Data Validation
- Schema, Mock Data and Validation Tests

## Project Structure

- app/schemas: Experiment data models
- app/data: Synthetic test records
- app/validation: Data validation logic
- tests: Module testing

## Important Notes

- Current schema is provisional (v0.1).
- Mock records are synthetic and are not NASA experimental findings.
- Schema and validation rules will be updated after official NASA resources are released.
