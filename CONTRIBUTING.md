# Contributing

- Keep module ownership isolated under `frontend/`, `backend/`, `data_analysis/`, `research_rag/`, and
  `computer_vision/`.
- Do not commit secrets, `.env` files, virtual environments, dependencies, build output, or local caches.
- Update canonical schemas and tests when API models change.
- Do not relabel mock or unverified data as official NASA findings.
- Run the smallest relevant test suite before pushing.
- Never commit undistributed NASA source media or copyrighted source documents without permission.
